TECS documentation
==================

**TECS** (Kokkos Cell Simulation) is a high-performance framework for agent-based cell simulations, built on top of the `Kokkos <https://kokkos.org/>`__ parallel programming model. It provides a flexible, extensible platform for simulating biological tissues, morphogenesis, and multicellular systems on CPUs and GPUs.

TECS handles neighbour discovery, force evaluation, time integration, and I/O — letting you focus on defining cell behaviours and running experiments.

Explore the `Kokkos docs <https://kokkos.org/kokkos-core-wiki/index.html>`__ for more on the underlying parallel programming model.
